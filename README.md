# BizTalk English — 비즈니스 미팅 영어

비즈니스 미팅 상황에 맞춘 사내 영어 학습 프로그램입니다.

- **PC**: Windows/macOS 설치 파일 (인터넷 없이 동작)
- **휴대폰**: 웹 주소로 열고 "홈 화면에 추가"하면 앱처럼 사용 (오프라인 지원)

## 메뉴 구성

| 구분 | 메뉴 | 내용 |
|---|---|---|
| 학습 | 홈 | 레벨·오늘의 목표, 이어서 학습하기, 오늘의 표현, 트랙별 진행률 |
| | 코스 | 8개 트랙 · 24개 레슨 (아래 표) |
| | 복습 | 간격 반복 플래시카드 (잊어버릴 때쯤 다시 출제) |
| 실전 | 실전 연습 | 스피킹 드릴, 회의 시뮬레이션, 스피드 챌린지, 오디오 학습 |
| | AI 회의 파트너 | Claude가 상대역을 맡아 음성·문자로 대화 + 턴마다 문장 교정 |
| 도구 | 표현 사전 | 전체 표현 검색, 즐겨찾기, 인쇄용 치트시트 |
| | 내 기록 | 레벨, 배지 12종, 학습 캘린더, 트랙별 진행률 |
| | 설정 | 화면 테마(화이트 & 연두 · 어둡게 · 기기 설정), 내 분야, 음성, 발음기호, AI 키, 학습 데이터 백업/복원 |

### 코스 (8개 트랙 · 24개 레슨 · 표현 168개 · 기술 용어 96개)

| 트랙 | 레슨 |
|---|---|
| 🧭 회의 진행 | 스몰토크 & 자기소개 · 회의 시작 & 안건 소개 · 회의 마무리 & 후속 조치 |
| 💬 토론 & 아이디어 | 의견 제시하기 · 동의와 반대 · 브레인스토밍 |
| 🌐 소통 & 원격 협업 | 끼어들기 & 확인하기 · 화상회의 · 일정 조율 |
| 📈 보고 & 협상 | 현황 보고 & 데이터 설명 · 발표 & 질의응답 · 협상 & 문제 해결 |
| 🔧 엔지니어링 미팅 | 설계 검토 · 장애 분석 & 근본 원인 · 테스트 & 품질 보고 |
| ⚙️ 엔지니어링 심화 | 사양·수치 말하기 · 리스크 & 안전 · 성능 & 데이터 분석 |
| 🌬️ HVAC 설계 | 부하 계산 & 장비 선정 · 풍량 & 덕트 설계 · 냉동 사이클 & 장비 |
| 🏢 HVAC 현장 & 운영 | 시운전 & TAB · 에너지 절감 & 자동제어 · 실내 공기질 & 민원 대응 |

**설정 → 내 분야**에서 트랙(예: HVAC)을 고르면 그 트랙이 홈·코스·실전 연습 맨 앞에 오고, 오늘의 안건도 그 분야부터 추천합니다.

HVAC 트랙은 실무 단위와 개념을 함께 다룹니다: 냉동톤↔kW↔BTU/h, CFM↔CMH, 정압(Pa·in. w.c.), 현열·잠열, 과열도·과냉각도, COP·IPLV, 저GWP 냉매, TAB 합격 기준(±10%), 팬 상사 법칙(동력 ∝ 회전수³), 이코노마이저·DCV·ERV, CO2·상대습도·이슬점·MERV 등급.

엔지니어링 레슨에는 **기술 용어 카드**(레슨당 8개)가 함께 들어 있습니다. 카드마다 공학 개념 설명과 예문이 있습니다. 예: 안전계수는 '견딜 수 있는 하중 ÷ 예상 하중', p99 지연 시간은 '요청의 99%가 끝나는 시간', 상관관계와 인과관계의 차이, FMEA의 RPN, 공차·공칭값·유효숫자, 수율, 회귀 결함. 용어 카드는 퀴즈·복습·표현 사전·스피드 챌린지에도 나옵니다.

레슨마다 4단계로 진행합니다: **핵심 표현**(듣기·녹음 비교) → **대화 듣기**(등장인물별 음성) → **롤플레이**(내 역할로 답하고 단어 단위 채점) → **퀴즈**(10문제, 80점 통과).

**헷갈리는 보기**: 퀴즈와 스피드 챌린지의 영어 보기는 정답 문장에서 한두 곳만 바꾼 문장입니다. 내용이 전혀 다른 보기를 지워 가는 방식으로는 정답을 고를 수 없습니다.

- 바꾸는 곳
  - 전치사·어법: by↔until, agree with↔agree to, suggest building↔suggest to build
  - 비슷한 단어: complaints↔compliments, mitigation↔migration
  - 수치·단위: 35 kW↔3.5 kW, CFM↔CMH
  - 공학 개념: approach↔range, R-32↔R-22
- 보기 4개 중 다른 보기들과 가장 많이 겹치는 것을 고르는 요령으로도 정답이 드러나지 않게 조합합니다.
- 답을 고르면 정답과 다른 단어에 밑줄이 그어지고, 결과 화면에서 내가 고른 답과 비교할 수 있습니다.

**발음기호**: 모든 표현과 기술 용어에 미국식 발음기호(IPA)가 붙어 있습니다.
- 표시되는 곳: 레슨, 용어 카드, 복습 카드, 표현 사전, 오디오 학습, 퀴즈 해설
- 레슨·복습 카드·스피킹 드릴에서는 영어 단어마다 바로 아래에 그 단어의 발음이 붙습니다.
- 네이버·YBM 사전과 같은 표기를 씁니다 (unit ˈjuːnɪt, sensible ˈsensəbl, action ˈækʃn). 발음기호 전용 글꼴(Noto Sans 서브셋)로 표시합니다.
- 표기법
  - `ˈ` 바로 뒤 음절을 세게, `ː` 앞 모음을 길게 읽습니다.
  - 문장 속 a · the · to · of · for 같은 기능어는 실제로 말할 때처럼 약하게 적습니다 (예: Shall we get started? /ʃæl wiː ɡet ˈstɑːrtɪd/).
- 설정 → 발음기호에서 끌 수 있습니다.

### 말하기 훈련 (Speak 스타일)

- **🗣️ 스피킹 드릴**: 표현마다 두 단계로 소리 내어 연습합니다.
  1. **듣고 따라 말하기**
  2. **한국어만 보고 영어로 말하기** (막히면 힌트)
  - 말하는 동안 실시간 자막이 뜨고, 말이 끝나면 단어별로 채점합니다. 80점을 넘으면 다음 단계로 넘어갑니다.
  - **핸즈프리**를 켜면 원어민 음성이 끝날 때 마이크가 자동으로 켜집니다.
  - 끝나면 약한 표현을 복습 카드로 보낼 수 있습니다.
  - 들어가는 곳: 레슨 화면, 실전 연습, 홈
- **🎙️ AI 음성 대화**: AI 회의 파트너의 기본 모드입니다.
  - 마이크를 누르고 말하면 자동으로 보내고, 상대 답변을 소리로 들려줍니다.
  - 턴마다 교정과 "더 자연스럽게" 표현을 보여 주고, **이렇게 따라 말하기**로 그 표현을 소리 내어 연습하면 바로 채점합니다.
  - 할 말이 막히면 **💡 뭐라고 말하지?**에서 예시 답변 2개를 볼 수 있습니다.
  - **⌨️ 입력해서 보내기**로 문자 대화로 바꿀 수 있습니다.

음성 인식은 휴대폰(Chrome·Safari)과 PC의 Chrome·Edge에서 웹 주소로 열 때 동작합니다. PC 설치판에서는 스피킹 드릴을 녹음 비교와 입력으로 연습합니다.

### 실전 기능

- **🎬 회의 시뮬레이션**: 가격 협상, 지연 보고, 팀 갈등 진행, 설계 검토 반론 대응, 고객에게 공차 이탈 설명하기, 준공 후 HVAC 냉난방 민원 대응 등 6개 시나리오. 상대의 말에 제한 시간(25초) 안에 답을 고르면 상대 반응이 달라지고, 끝나면 **정중함·명확성·주도성** 점수와 S~C 등급을 받습니다.
- **⚡ 스피드 챌린지**: 60초 동안 한국어 뜻에 맞는 영어 표현을 비슷한 보기 중에서 맞힙니다. 연속으로 맞히면 콤보가 쌓이고, 틀리면 3초가 깎입니다. 틀리면 정답과 다른 곳을 잠깐 보여 주는데, 그동안 시계는 멈춥니다.
- **🎧 오디오 학습**: 영어 → 한국어 뜻 → 천천히 영어 순서로 자동 재생. 출퇴근길 핸즈프리 학습용.
- **🤖 AI 회의 파트너**: 해외 파트너 첫 미팅, 단가 협상, 현황 보고, 기술 설계 검토, 장애 회고(포스트모템), 고객사와 사양·공차 협의, HVAC 설계 검토, HVAC 냉난방 민원 협의 등 상황을 고르거나 직접 만들어 AI와 회의합니다. 내가 한 말마다 교정 문장·더 자연스러운 표현·한 줄 팁을 받고, 회의가 끝나면 리포트와 외울 표현을 복습 카드로 저장할 수 있습니다.
- **🏆 동기 부여**: 학습할 때마다 XP가 쌓여 인턴 → 글로벌 CEO까지 레벨업, 하루 목표 60 XP, 연속 학습일, 배지.

## 설치 · 실행

### PC (설치 파일)

**다운로드: [Releases 최신 버전](https://github.com/axd5501-bit/company/releases/latest)** — GitHub 계정 없이 받을 수 있습니다.

- Windows: `BizTalk-English-Setup-x.y.z.exe`
- macOS: `BizTalk-English-x.y.z-mac.dmg`

설치 파일은 GitHub Actions(*Build installers*)가 자동으로 빌드합니다.
- 기본 브랜치에 `package.json`의 `version`을 올려서 push하면 `v<버전>` 릴리스가 자동으로 만들어지고 설치 파일이 첨부됩니다.
- `v2.5.0` 같은 태그를 직접 올려도 됩니다.
- 릴리스 전 테스트 빌드는 **Actions** 탭 → 실행 기록 → 하단 **Artifacts**에서 받을 수 있습니다. 이 경로는 GitHub 로그인이 필요합니다.

설치 시 참고:
- **Windows**: 코드 서명이 없어 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- **macOS**: 처음에는 Finder에서 앱을 **우클릭 → 열기**로 실행하세요.

**자동 업데이트 (v2.7.0부터)**: 한 번 설치하면 다시 내려받을 필요가 없습니다.
- **Windows**
  - 앱을 켤 때와 6시간마다 새 버전을 확인해 백그라운드로 받아 둡니다.
  - 다 받으면 "지금 다시 시작 / 나중에"를 묻고, 나중에를 고르면 앱을 닫을 때 설치합니다.
  - 학습 기록은 그대로 유지됩니다.
  - 동작 방식: 릴리스에 첨부되는 `latest.yml`을 `electron-updater`가 확인합니다.
- **macOS**: 코드 서명이 없으면 자동 설치를 할 수 없어서, 새 버전이 나오면 알림을 띄우고 다운로드 페이지를 열어 줍니다. Apple 개발자 인증서로 서명하면 Windows처럼 자동 설치로 바꿀 수 있습니다.

### PC에서 설치 없이 쓰기 (추천)

Chrome이나 Edge에서 웹 주소를 열고, 주소창 오른쪽의 **앱 설치** 아이콘을 누르면 바탕화면·시작 메뉴에 앱으로 설치됩니다.
- 항상 최신 버전이 열립니다. 켜 둔 상태에서 새 버전이 나오면 "🌱 새 버전이 준비됐어요 · 지금 적용" 안내가 뜹니다.
- 설치판과 달리 **말하기 채점·AI 음성 대화**도 쓸 수 있습니다.
- 설치판과 웹 앱은 학습 기록을 따로 저장합니다. 옮길 때는 **설정 → 학습 데이터 → 내보내기 / 가져오기**를 쓰세요.

### 휴대폰 (웹 앱)

`app/` 폴더가 GitHub Pages로 자동 배포됩니다 (*Deploy web app* 워크플로).

1. **최초 1회**: 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꾸고, Actions 탭에서 *Deploy web app*을 다시 실행합니다.
2. 배포 주소(예: `https://<계정>.github.io/<저장소>/`)를 휴대폰에서 엽니다.
3. **홈 화면에 추가** — iPhone(Safari): 공유 → 홈 화면에 추가 / Android(Chrome): ⋮ → 홈 화면에 추가

휴대폰 Chrome·Safari에서는 **말하고 채점**(음성 인식) 기능도 쓸 수 있습니다. PC 설치판에는 음성 인식 서버가 없어서 녹음 비교와 입력 채점 방식을 씁니다.

> 저장소가 공개(public)이면 배포된 웹 앱도 누구나 열 수 있습니다. 학습 기록과 API 키는 각자의 기기에만 저장되고 서버로 전송되지 않습니다.

### 공통 설정

- **영어 음성이 안 나올 때**: 앱은 기기에 설치된 음성을 씁니다. 한국어 Windows는 설정 → 시간 및 언어 → 음성 → **음성 추가**에서 "English (United States)"를 설치하세요.
- **마이크**: Windows 설정 → 개인 정보 및 보안 → 마이크 → 데스크톱 앱 액세스 허용.
- **AI 회의 파트너**: [console.anthropic.com](https://console.anthropic.com)에서 Claude API 키를 발급받아 **설정 → AI 회의 파트너**에 저장합니다. 키는 그 기기에만 저장되며 백업 파일에도 포함되지 않습니다. 대화한 만큼 API 요금이 부과됩니다. 모델은 `claude-opus-5-5`이고, 안전 분류기가 요청을 거절하면 서버가 권장 모델로 자동 재시도하도록(`fallbacks: "default"`) 설정되어 있습니다.
- **PC ↔ 휴대폰 기록 옮기기**: 설정 → 학습 데이터 → 내보내기 / 가져오기.

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install          # 의존성 설치
npm start            # 데스크톱 앱 실행 (개발 모드)
npm test             # 채점·퀴즈·복습·레벨·배지 로직과 콘텐츠, 오프라인 캐시 목록 검증
npm run dist:win     # Windows 설치 파일 (Windows에서 실행)
npm run dist:mac     # macOS dmg (macOS에서 실행)
npm run build:vendor # Anthropic SDK를 app/vendor/anthropic-sdk.js 로 다시 번들
npm run ipa          # 새로 추가한 표현·용어에 발음기호(ipa) 채우기 (--all: 전부 다시)
```

웹으로 확인할 때는 `app/` 폴더를 아무 정적 서버로 띄우면 됩니다 (예: `npx serve app`). `app/index.html`을 파일로 바로 열어도 동작하지만 오프라인 캐시는 웹 주소로 열 때만 켜집니다.

```

  css/style.css         디자인 (화이트 & 연두 테마, 다크 테마, 반응형, 인쇄)
```

### 콘텐츠 추가·수정

- **레슨**: `app/js/data.js`의 `LESSONS`에 추가하고 `TRACKS`의 해당 트랙 `lessons`와 `LEVELS`에 id를 넣으세요.
  - `expressions[].blank`: 빈칸 퀴즈에서 비울 단어 (문장 안에 반드시 포함)
  - `expressions[].ipa`, `terms[].ipa`: 발음기호. 직접 쓰지 말고 `npm run ipa`로 채우세요. 사전에 없는 단어가 있으면 목록을 보여 주니 `scripts/ipa.mjs`의 `OVERRIDES`에 추가하면 됩니다.
  - `expressions[].swaps`: 비슷한 오답을 만드는 규칙. `"바꿀 부분>오답1|오답2"` 형식으로 쓰고, 문장 안의 겹치지 않는 자리 1~3곳을 지정합니다.
    - 예: `["report>proposal", "Friday>Monday"]` → `report by Monday` / `proposal by Friday` / `proposal by Monday`
    - 오답도 **원어민이 실제로 쓰는 자연스러운 영어**여야 합니다. 문법이 틀린 문장(`until`/`till` 혼동, 시제 오류 등)을 쓰지 말고, 한두 단어 차이로 **뜻만 달라지게** 만드세요. 관사(a/an)가 바뀌는 단어는 관사까지 함께 바꿉니다(`an interesting idea>a risky idea`).
    - 자리가 2곳 이상이면 A만 / B만 / A+B를 바꾼 2×2 조합으로 오답을 만듭니다.
    - 한 자리에만 오답을 3개 넣을 때는 세 오답 모두 같은 단어를 바꿔야 합니다. 서로 다른 단어를 바꾸면 다수결로 정답이 드러나서 `npm test`가 실패합니다.
  - `terms` (선택): 기술 용어 카드 `{ en, ko, def(개념 설명), ex(예문) }`. 넣으면 레슨 화면·퀴즈(용어 문제 2개)·복습·사전·스피드 챌린지에 자동으로 반영됩니다.
  - `dialogue.you`: 롤플레이에서 학습자가 맡는 역할
  - `situations[].answer`: 정답 보기 인덱스 (화면에서는 섞여서 나옴). 상황 문제의 오답도 자연스러운 영어로, 상황에 맞지 않거나 뜻이 다른 문장을 넣습니다.
- **시뮬레이션**: `app/js/scenarios.js`. 단계마다 평가 역량(`polite`/`clear`/`lead`)과 등급 0·1·2 답변 3개, 각 답변에 대한 상대 반응을 넣습니다.
- 앱 파일을 바꾸면 `app/sw.js`의 `VERSION`을 올려야 휴대폰에 새 버전이 반영됩니다.

`npm test`가 잡아 주는 실수:

- 빈칸 단어 누락
- 정답 인덱스 오류
- 알 수 없는 화자
- 시나리오 등급 누락
- 오프라인 캐시 누락
- 오답(swaps) 형식 오류, 다수결로 정답이 드러나는 오답 조합
- 발음기호(ipa) 누락·형식 오류
