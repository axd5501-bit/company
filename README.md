# BizTalk English — 비즈니스 미팅 영어

비즈니스 미팅 상황에 맞춘 사내 영어 학습 프로그램입니다. Windows/macOS에 설치해서 쓰는 데스크톱 앱이며, 인터넷 연결이나 서버 없이 동작합니다.

## 학습 구성

회의 한 번의 흐름을 따라가는 9개 레슨, 핵심 표현 63개.

| # | 레슨 | 주요 상황 |
|---|------|-----------|
| 1 | ☕ 스몰토크 & 자기소개 | 회의 전 인사, 담당 업무 소개 |
| 2 | 📋 회의 시작 & 안건 소개 | 회의 목적, 안건, 시간, 회의록 담당 |
| 3 | 💬 의견 제시하기 | 의견 말하기, 의견 묻기, 덧붙이기 |
| 4 | 🤝 동의와 반대 | 정중한 반대, 절충안 제시 |
| 5 | ✋ 끼어들기 & 확인하기 | 질문하려고 끼어들기, 되묻기, 요약해서 확인 |
| 6 | 📊 현황 보고 & 데이터 설명 | 진행 상황, 수치 증감, 원인 설명 |
| 7 | 💼 협상 & 문제 해결 | 조건 제안, 예산·납기 조율, 답변 보류 |
| 8 | 💻 화상회의 | 음소거, 소리 끊김, 화면 공유 |
| 9 | ✅ 회의 마무리 & 후속 조치 | 요약, 실행 항목, 담당자, 기한 |

레슨마다 네 단계로 진행합니다(단계별 25%).

1. **핵심 표현**: 원어민 음성 듣기(보통 속도/천천히). 내 목소리를 녹음해서 원어민 발음과 비교할 수 있습니다.
2. **대화 듣기**: 실제 회의 장면 대화문. 등장인물마다 다른 음성으로 읽어 주고, 한국어 해석은 켜고 끌 수 있습니다.
3. **롤플레이**: 대화 속 내 역할을 직접 맡습니다. 한국어 뜻을 보고 영어로 답하면 모범 답안과 단어 단위로 비교해서 점수를 매기고, 빠뜨린 단어를 표시해 줍니다.
4. **퀴즈**: 상황 판단, 뜻 고르기, 빈칸 채우기, 문장 배열 문제 10개. 80점 이상이면 통과입니다.

그 밖의 기능:

- **간격 반복 복습**: 익힌 표현을 잊어버릴 때쯤 다시 보여 주는 플래시카드(SM-2 방식).
- **홈 대시보드**: 연속 학습일, 완료한 레슨, 익힌 표현, 오늘 복습할 카드, 오늘의 표현.
- **학습 데이터 내보내기/가져오기**: 기록은 PC에 저장되며, PC를 바꿀 때 백업 파일로 옮길 수 있습니다.

## 설치 파일 받기

설치 파일은 GitHub Actions가 자동으로 빌드합니다.

- **빌드할 때마다**: 저장소의 **Actions** 탭에서 *Build installers* 실행을 고른 뒤, 하단 **Artifacts**에서 다운로드합니다.
  - `BizTalk-English-Windows` → `BizTalk-English-Setup-x.y.z.exe`
  - `BizTalk-English-macOS` → `BizTalk-English-x.y.z-mac.dmg`
- **정식 배포**: `v1.0.0` 같은 태그를 푸시하면 GitHub **Releases** 페이지에 설치 파일이 첨부됩니다.

  ```bash
  git tag v1.0.0
  git push origin v1.0.0
  ```

### 설치 시 참고

- **Windows**: 코드 서명 인증서 없이 빌드했기 때문에 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요. 회사에 코드 서명 인증서가 있으면 `CSC_LINK`/`CSC_KEY_PASSWORD` 시크릿을 추가해서 경고를 없앨 수 있습니다.
- **macOS**: 서명이 없는 앱이라 처음에는 Finder에서 앱을 **우클릭 → 열기**로 실행해야 합니다.
- **영어 음성이 안 나올 때**: 앱은 OS에 설치된 음성을 사용합니다. 한국어 Windows에는 영어 음성이 없는 경우가 많습니다.
  - Windows: 설정 → 시간 및 언어 → 음성 → **음성 추가** → "English (United States)" 설치 후 앱을 다시 실행
  - macOS: 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기 → 시스템 음성에서 영어 음성 추가

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install        # 의존성 설치
npm start          # 앱 실행 (개발 모드)
npm test           # 채점·퀴즈·복습 로직과 콘텐츠 검증 테스트
npm run dist:win   # Windows 설치 파일 빌드 (Windows에서 실행)
npm run dist:mac   # macOS dmg 빌드 (macOS에서 실행)
```

`app/index.html`을 Chrome이나 Edge로 바로 열어도 동작합니다. 브라우저에서는 **🎤 말하고 채점**(음성 인식 자동 채점) 버튼이 추가로 나타납니다. 데스크톱 앱에는 음성 인식 서버가 없어서, 녹음 비교와 입력 채점 방식을 씁니다.

### 폴더 구조

```
app/                화면 (HTML/CSS/JS, 빌드 과정 없음)
  index.html
  css/style.css
  js/data.js        레슨 콘텐츠 ← 표현/대화/문제 추가는 여기서
  js/core.js        채점, 퀴즈 생성, 복습 일정, 진행률 계산 (순수 로직)
  js/app.js         화면 렌더링과 이벤트 처리
electron/main.js    데스크톱 창, 마이크 권한
build/icon.png      앱 아이콘 (Windows .ico / macOS .icns 자동 변환)
tests/              node:test 단위 테스트
.github/workflows/  설치 파일 자동 빌드
```

### 레슨 추가·수정

`app/js/data.js`의 `LESSONS` 배열에 객체를 추가하면 됩니다.

- `expressions[].blank`: 빈칸 퀴즈에서 비울 단어. 문장(`en`) 안에 반드시 들어 있어야 합니다.
- `dialogue.you`: 롤플레이에서 학습자가 맡는 역할 키(`roles`의 키).
- `situations[].answer`: 정답 보기의 인덱스. 화면에서는 보기 순서가 섞여서 나옵니다.

`npm test`가 빈칸 단어 누락, 정답 인덱스 오류, 알 수 없는 화자 같은 콘텐츠 실수를 잡아 줍니다.
